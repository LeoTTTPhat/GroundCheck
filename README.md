# GroundCheck

The complete reproduction package is in [`Artifact/`](Artifact/README.md).

```bash
cd Artifact
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
bash scripts/run_all.sh --check
bash scripts/run_all.sh --analysis
```

See the package instructions for complete experiment reruns and input provenance.
